# CHROMATIC RESENHA

2D Fighting Game – Street Fighter / Super Smash Bros inspired.

## Run

Open `index.html` in a browser or serve:

```bash
npx serve .
```

## Deploy

- GitHub: push this folder
- Vercel / Netlify: connect repo or drag folder

## Controls

**PC P1:** WASD move, F attack, G strong, H special, S block  
**PC P2:** Arrows + 1/2/3 + Down  
**Mobile:** On-screen buttons

## Modes

- Story Mode: 5 opponents + boss
- Versus: Local 2-player
